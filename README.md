# Rxc07dorj Android

Rxc07dorj web prototype packaged as an Android WebView app.

## Build
Open this folder in Android Studio, let Gradle sync, then:
Build > Generate App Bundle / APK > Generate APK.

The app ID is `com.rxc07dorj`, version 1.0.

This project contains educational/simulation features only and does not connect to or access third-party accounts.
